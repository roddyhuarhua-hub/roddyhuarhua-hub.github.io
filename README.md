# roddyhuarhua-hub.github.io

Portafolio personal de Roddy Huarhua: relaciones comunitarias, conflictos socioambientales y ciencia de datos con Python.

Sitio: https://roddyhuarhua-hub.github.io

- `index.html`: todo el sitio en un solo archivo (HTML y CSS).
- `images/`: figuras de los proyectos (JPG livianos).
- `videos/`: reels (menos de 4 MB cada uno).
- `files/`: CV en PDF.

Para agregar un proyecto, copia un bloque `<article class="project">` o `<article class="mini">` en `index.html` y cambia el texto, la imagen y los enlaces.
